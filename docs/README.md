## API reference

The reference is generated by TypeDoc from the doc comments of the public entry points. It is not committed.

```sh
npm run docs:api   # writes HTML to out/api/
```

A CI job (`.github/workflows/docs-api.yml`) builds it with warnings as errors.
The [release checklist](releasing.md) says where it is published.

## Reference

- [Diagnostic codes](reference/diagnostics.md): every stable code, with its message and parameters. Generated.
- [Wire format v1](reference/wire-format.md): the JSON of a run request and its answer. JSON Schema files are in [`schemas/`](../schemas/README.md).
