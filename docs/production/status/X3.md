## Done
Blocks, function bodies and the top level now run their statements in order. Assignment to a local name and `if!` work. A record path as a target fails with `eval.writesNotSupported`.

- `src/language/minab-interpreter.ts`: one statement runner, `runStatements` (`let`, assignment, `if!`). X4, X5 and X6 extend it. `run`, `callFunction` and the `Block` case all use it.
  - A block gets its own scope (a frame marked `scopeOnly`). It holds names only, so `.` and `^` and the compiler's frame counting do not change. Inner `let`s shadow outer ones; the outer value is back after the block.
  - Each frame now keeps the declared type of its names, so `=` and the compound operators keep the type (a `DECIMAL` stays exact).
  - `+=` joins text (D13); `-=` `*=` `/=` use the same code and errors as the operators; `?=` skips the right side when the value is not `null`; `|=` merges an object (a `null` counts as `{}`).
  - A target that is not a local name (a record path, a host input) fails with `eval.writesNotSupported`.
  - `if!` with `else if` and `else`; branch blocks may have a tail, it is run and dropped.
  - Call depth: already counted per user function call by R4's `enterCall`. A test now covers a function with statements.
- Playground: `CHECK_ONLY` no longer lists `AssignmentStatement`, `IfStatement` or `Block`. A new gallery example `statements-in-function` and a cheat sheet entry for assignment. `playground/README.md` updated.
- `test/statements.test.ts` (new, 14 tests). `test/spec-examples.test.ts` now also runs each checked spec and showcase example and fails if it is refused as an old "not executed yet" statement.
- `changes/X3.md`.
