# C7 `GROUPBY` on a related field

Status: done
Date: 2026-10-02
Branch / PR: sema/nice-clarke-71fruz

## Done
A `GROUPBY` key that walks a relation, like `.customer.country`, now compiles to one `LEFT JOIN` for each hop. `GROUP BY` and `SELECT` use the same joined column, so Postgres accepts the query. A row with a null relation forms one `null` group.

- `src/language/minab-sql-compiler.ts`: new `joinGroupKeys` and `groupKey`. `KEY`, `HAVING` and `ORDERBY` use the same column. Join aliases are `_g0`, `_g1`, and so on.
- Keys that are a relation itself (`GROUPBY .customer`) are not changed. The SQL is the same as before.
- `test/sql-compilation.test.ts`: one new test for the joined SQL. No old expected SQL changed.
- `test/queries/cases/c7-groupby.cases.ts`: one hop, two hops, a null relation, `HAVING` and `ORDERBY` on `KEY`, and `GROUPBY .customer` still working.
- `changes/C7.md`: changelog fragment.
