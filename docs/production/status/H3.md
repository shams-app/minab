## Done
`examples/nestjs/` is a NestJS 11 app with TypeORM and Postgres. It is its own npm package, CommonJS, and installs Minab from the packed tarball (`npm run setup`). It shows a stored correlated rule in a request transaction, a stored query and the H2 run endpoint.

- `examples/nestjs/src/`: `schema.ts` (the read surface), `migrations/` (tables, `minab_program (id, version, source, language_version)`, two seeded programs), `program-store.ts`, `app.module.ts`, `orders.controller.ts`, `reports.controller.ts`, `data-source.ts`, `migrate.ts`, `main.ts`.
- `POST /orders/validate`: inserts the order in a `QueryRunner` transaction, runs `order-limit` v1 with a data port bound to that transaction, commits on `true`, rolls back and answers 422 with the rule id on `false`. A broken stored program also rolls back and answers 422 with its codes (the H2 filter).
- `GET /reports/top-customers`: runs the stored query `top-customers` v1.
- `POST /minab/run`: the H2 controller, stored programs only.
- `examples/nestjs/README.md`: the walkthrough for G1, with the security note (the schema is the read surface).
- `examples/nestjs/test/app.e2e.ts`: 11 tests: commit path, rollback path, closed orders, bad body, report, run endpoint, refused source text, unknown program, broken stored program (422 with codes, rollback), logs in development and in production.
- `.github/workflows/example-nestjs.yml`: Postgres 16 service, root install, install the tarball, migrate, e2e tests.
- `test/analysis.test.ts`: the example loop now skips folders that have no `<name>.minab`, as `examples/README.md` and the other example tests already say. It failed on `examples/nestjs` without this change (checked).
- Root `package.json`: `files` now has `!examples/nestjs`. `examples/README.md` updated.
- `src/nestjs/` was not changed.
