## Done
`examples/browser/` is a small Vite + TypeScript app with no UI framework. It is its own npm package and installs Minab from the packed tarball (`npm run setup`). It shows the three browser pieces working together, and Playwright tests prove it in Chromium.

- Page 1, form: a local rule (`.end_date > .start_date`) runs in the worker on every change with no network call. The stored rule `order-limit` v1 runs on submit through `routeByTier`: the browser sends `program.ref` and the record fields the rule reads, never SQL, a schema or program text. The page shows the verdict and the error code.
- Page 2, editor: Monaco with `registerMinab` (E5), the example schema, error markers (also listed under the editor) and completion after `.`. Monaco loads only when this page opens.
- `examples/browser/tests/browser.spec.ts`: 4 tests: local path with zero requests to `/minab`; delegated path with the request body checked; type-error marker; completion of a column after `.`.
- `.github/workflows/example-browser.yml`: Postgres 16 service, pack, install and migrate the NestJS example, start its server, install the browser example and Chromium, run Playwright.
- `examples/browser/README.md` (G1 cites it). Root `package.json`: `files` has `!examples/browser`. `examples/README.md`: one word updated.
- `src/browser/` and `src/monaco/` were not changed. No problem found in them.
