# L3 Names in any language, quoted names, physical names

Status: done
Date: 2026-10-03
Branch / PR: sema/intelligent-clarke-6ddptg

## Done

Minab can now name any table or field. Plain names use any Unicode letter. Names with spaces or symbols go in backticks. A schema can give a table or column a `sqlName`; the SQL uses it, and result rows keep the Minab names.

- Grammar (`src/language/minab.langium`): `terminal ID` uses Unicode property escapes (`\p{L}`, `\p{N}`, `u` flag; U+200C and U+200D allowed after the first character). New `QUOTED_NAME` terminal and `Name returns string: ID | QUOTED_NAME`, used in every place a user-facing name is written.
- `src/language/minab-value-converter.ts`: removes backticks and escapes.
- `src/language/minab-token-builder.ts`: Langium gives no "longer alternative" to a `u`-flag terminal, so `FROMا` was lexed as `FROM` + a name. This class fixes it.
- `schema.ts`, `host/config.ts`: `sqlName` on tables and columns; both meanings (`primaryKey` is a schema name, `foreignKey` is a physical name) are written down.
- `minab-sql-compiler.ts`: quotes `sqlName ?? name`. A bare field in `SELECT` without `AS`, and `SELECT *`, are aliased back to the Minab name when the column has a `sqlName`.
- `host/ddl.ts`: creates tables and columns with their physical names; seeds still use Minab names.
- Spec §2.3 "Names" and the §11 grammar block; showcase §16.
- Playground: tokenizer and Monaco word pattern accept both kinds of name; Persian dataset (`کتاب‌فروشی`) and gallery example `persian-names`.
- `vscode-extension/language-configuration.json`: backtick auto-closing and surrounding pair.
- Tests: `test/names.test.ts`, `test/differential/cases/l3-names.cases.ts`, `playground/test/tokens.test.ts`, spec fixture extended.
