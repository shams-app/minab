## Done
`createMinab` / `prepare` / `PreparedProgram` exist in `src/runtime/`. They use no Node API, no DOM and no `pg`. The package `exports` map is complete.

- `src/runtime/`: `minab.ts` (`createMinab`, `cacheStats`, `dispose`), `prepare.ts` (diagnostics with codes, ranges and params; `ok`; `kind`; `resultType`; `compile()`; `run()`; the `expect` check), `service-cache.ts` (LRU, default 16, key = schema version or a hash, plus rule context), `program-kind.ts`, `types.ts`, README.
- Each `prepare` has its own URI `minab:///prepared/<n>.minab` and deletes its document in a `finally`. The prepared program holds the AST, the interpreter and the compiler only.
- New diagnostic code `type.unexpectedResultType` (registry, generated doc, test case `via: 'runtime'`).
- `MinabSchema` has an optional `version`.
- `package.json`: `exports` for `.`, `./node`, `./nestjs`, `./browser`, `./browser/worker`, `./browser/pglite`, `./monaco`, `./lsp`, `./host`, `./package.json`; `typesVersions`; `main` and `types`; optional peers `pg`, `@nestjs/common`, `@nestjs/core`, `rxjs`, `reflect-metadata`, `@electric-sql/pglite`, `monaco-editor`. `package-lock.json` and `bun.lock` updated.
- Stubs with `notReady` and a README: `src/node` (H1), `src/nestjs` (H2), `src/browser/{index,worker}` (H4), `src/browser/pglite` (H5), `src/monaco` (E5).
- `./lsp` is `startMinabServer()` in `src/language/server.ts`. `main.ts` now only calls it, so the extension bundle works as before. `./host` is `src/host/index.ts`.
- `playground/src/engine/program.ts` now uses `classifyProgram` from the runtime for kind and result type. Nothing else in the playground or the CLI changed.
- Tests: `test/runtime.test.ts`, `test/runtime-concurrency.test.ts`, `test/runtime-imports.test.ts`, `test/release.test.ts` (exports targets, map, peers), `test/support/runtime.ts`.
