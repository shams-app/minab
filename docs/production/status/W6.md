## Done
The Data panel now follows the open example, `useTheme` reports the theme the page really shows, and the playground lint covers all of `src` with no findings. Depends W4 was `Status: done`. The card lists no decisions.

- **Data panel (Build 1).** There were two causes.
  - `DataView.tsx` selected a table only when no table was active, so the previous example's table stayed. Now it keeps the active table only while the dataset has it, else it selects the dataset's first table. A new `dataKey` (from `useHost`: dataset, schema, seed) loads the table again, because two datasets can have a table with the same name.
  - The preview was sent to the engine before the new host. `state/controller.ts` now keeps the `setHost` promise, and the new `previewTable`, `runSql` and `resetDatabase` wait for it. `useHost` uses them. `useTablePreview` drops an answer that is older than the latest load, and clears the rows of another table while loading.
  - The SQL console starts with `SELECT * FROM "<table>" LIMIT 10;` on the dataset's table (`starterSql`). It starts fresh when the dataset changes.
- **Theme (Build 2).** `useTheme.ts`: new `effectiveTheme(preference, matchMedia)`. The CSS shows light only for `prefers-color-scheme: light`, so the hook now asks that query. With no OS preference it says `dark`.
- **Lint (Build 3).** 14 findings fixed (the card said 15; `src/engine/worker.ts` had none any more): `void navigate(…)` in `useCommands.ts`, `PlayPage.tsx`, `ExamplesPage.tsx`, `ReferencePage.tsx`, `Root.tsx`, `Workbench.tsx`; a type import in `content/types.ts`. The `lint` script is now `oxlint --type-aware src test scripts`. No engine behavior changed.
- **Tests (Build 4).**
  - `playground/tests/data-panel.spec.ts` (Playwright, 3 tests): demo → Persian shows `مشتری` and `سفارش` and no `Customer`; back to an English example shows `Customer` again; a direct load of `/play?example=persian-names` shows `rows in مشتری` and no `unknown table`; the SQL console's first query runs on `مشتری`.
  - `playground/test/theme.test.ts` (Vitest, 4 tests). The hook had no unit test file, so I added one for its logic (`effectiveTheme`), not a Playwright check: nothing on the page shows `effective`.
  - Checked once without the fix: all 3 Playwright tests fail (no `rows in مشتری`; the console text was the `Customer` query). With the old dark-query logic, 2 theme tests fail.
- READMEs: `playground/README.md` (lint, theme test, Data panel), `playground/tests/README.md`.
