## Done
The design system, the app shell and the workbench now follow the approved design (`playground/design/handoff.md`, "Terminal Noir"). Engine, state, hooks and content are untouched. The canvas opened with the Artifact tool, so there was nothing to ask the owner.

- **Tokens.** `src/styles/tokens.css` is rewritten with the handoff values. Dark is on `:root`. Light is in two identical blocks. New tokens: `--glow-record`, `--glow-pushdown`, `--pushdown-ring`, `--overlay-blur`, `--scrim`, `--grid-line`, `--theme-color`, plus `--glow-accent` and `--glow-success` (mine, for the primary button and the status dot). Fonts are self-hosted in `public/fonts/` (Geist, JetBrains Mono, OFL licenses).
- **Primitives.** Button, IconButton, Badge (glyphs ✓ ✕ ⇣, dashed check-only), Tabs, Kbd, Toggle, Callout, EmptyState (new optional `glyph`, new tone `success`), Toast, CodeBlock (caption bar with Wrap and Copy). New `Mark` (the tulip) and `Lockup`. New icons `terminal` and `more`.
- **Shell.** Lockup, 212 px search button, active nav with `aria-current`, a Menu button below 720 px.
- **Workbench.** Toolbar with the divider and a "More actions" menu when narrow, the five engine pill states, editor status bar, separators with a grip, the narrow layout (tabs, chips that scroll sideways, 52 px floating Run, 44 px targets).
- **Output.** Verdict card ("Rejected" for a field rule), value view, tables, Execution trace with the lime ring on hover, SQL, AST, Problems (with the error code), and the **Console** tab as a label, value and `line:col` row.
- **Host panel and overlays.** Schema cards, form grid, presets, command palette (icons, bold matches, key hints), drawer and toast (glass, scrim). An error toast stays until it is closed.
- **Monaco.** The editor theme follows the tokens. Light is now chosen only when the OS asks for it. Widgets use the opaque raised surface. Ligatures are off.
- **Assets.** `favicon.svg` (mark B), `apple-touch-icon.png`, `og-image.png` (sources in `design/assets/`), `theme-color` and font preload in `index.html`.
- **Linter.** `playground/.oxlintrc.json`, a `lint` script (with `prelint`), `oxlint` and `oxlint-tsgolint` as dev dependencies (same versions as the root, D08), and one step in `.github/workflows/lint.yml`. `package-lock.json` and `bun.lock` are updated.
- **Test.** `test/design-tokens.test.ts` (51 tests): the two light blocks are identical, light and dark define the same tokens, and every syntax color passes AA in both themes.
- **Docs.** `playground/README.md`, `design/contract.md` (dark on `:root`), new `public/fonts/README.md` and `design/assets/README.md`. Fragment `changes/W2.md`.

- **One small edit outside the card's file list.** `src/monaco/CodeEditor.tsx`: `fontLigatures: false` (the design shows `!=` and `<=` as typed). Nothing else in `src/monaco` changed except `theme.ts`, which is on the list.
- **Mobile top bar.** The handoff shows lockup, Search and Menu. The theme button stays visible next to them (the GitHub link moved into the menu), because the theme must be reachable on a phone.
- **Spinner and reduced motion.** Durations are 0 and pulse, rise, pop and flip animations stop. The loading spinner keeps turning, because it shows that work is going on.
- **Screenshots.** I took and checked them (workbench at 1440 px and 375 px, light and dark, plus Execution hover, Console, Problems, palette). I cannot attach images to a pull request with the tools in this session, so the owner must attach them. They are not committed.
