- Host functions are not declared yet (R3). Until then `localHostFunctions` (an option of `createMinab`) lists the local ones. R3 should replace it with the host function declarations.

- Extra fields beyond ADR section 7: `dependencies` (record fields plus foreign keys of `ref` relations read, so `.customer` also reacts to `customer_id`), `readsWholeRecord`, `userFunctions`, `builtins`. The ADR has no `userFunctions`/`builtins`; the card asks for them.
- `readsFieldValue` and `inputs` follow the ADR names. `inputs` lists names only, not paths.
