## Done
App code can call `run` and not care where the program runs. A program of tier `local` runs in the browser worker with no network call. A program of tier `data` goes to the server by id and version, through wire format v1 (decisions D28, D30, D34). The browser bundle is measured and guarded.

- `src/browser/remote.ts`: `createRemoteMinab({ endpoint, fetch?, headers?, maxBatch?, types?, events? })`. Runs made in the same tick go in one request (split at `maxBatch`, default 100). An `AbortSignal` ends a run with `cancelled` at once and aborts the `fetch` when all runs of the request are aborted. Answers are decoded with R6.
- `src/browser/route.ts`: `routeByTier({ local, remote, events? })`. It never sends SQL, a schema or source to the server. A program that fails its check stays local.
- `src/browser/console.ts`: `consoleEventSink()` and `emitLogs()`. Remote `logs` go to the same sink as local events.
- `src/browser/pglite.ts` (replaces the R2 stub): `createPgliteDataPort({ schema, seed?, script? })`, with `citext`, tables from `src/host/ddl.ts`.
- New code `wire.remoteFailed` (network failure, a non-Minab HTTP error, a missing result). It is in the registry and `docs/reference/diagnostics.md`.
- `scripts/browser-bundle.mjs` (+ `.d.mts`), `bench/bundle.json`, `bench/README.md`, `.github/workflows/browser-bundle.yml`. The guard fails if `pg`, `node:*` (or a bare Node built-in), `langium/node` or `vscode-languageserver/node` is in a bundle.
- Tests: `test/browser/remote.test.ts` (17), `bundle.test.ts` (2, includes importing `src/node` on purpose), `pglite.test.ts` (2).
- Docs: `src/browser/README.md`, `test/browser/README.md`, `scripts/README.md`. Fragment: `changes/H5.md`.
