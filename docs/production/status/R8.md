# R8 The playground engine runs on the runtime API

Status: done

## Done
The playground engine now does its language work through `createMinab`, `prepare` and `run`. The message protocol (`protocol.ts`) and the UI did not change.

- `playground/src/engine/language.ts`: one `Minab` per host (schema + rule context), cached with the old six-host rule. `LanguageHost` stays, but only parses a syntax tree. It no longer validates.
- `playground/src/engine/engine.ts`:
  - `analyze` uses `prepare` (diagnostics, kind, result type) and `compile()` (SQL tab). Runtime codes map to the old texts.
  - `run` uses `PreparedProgram.run` with a data port (PGlite or the fixture data) and an event sink. The `statement` event gives the source range. The port fills rows, time and error.
  - A failed statement still gives the old `datasource` error with the database message and the formatted SQL.
  - The "not executed yet" refusal is read from the `eval.failed` error (`params.reason`).
  - When the program `needsData` (from the analysis), PGlite boots before the run clock starts. A program with no data never boots it.
- `playground/src/engine/program.ts`: kind and result type come from the runtime. Added `nodeAt` (finds the node for a statement range).
- Limits are now on in the playground (they were off). The runtime defaults apply, except `wallTimeMs`: 10 seconds.
- Docs: `playground/README.md`, `src/runtime/README.md`, two comments in `src/language/minab-interpreter.ts` (no logic change).
- Tests: `playground/test/execution-trace.test.ts` (new) compares the Execution tab data of three gallery examples with a file recorded from the old engine (`playground/test/fixtures/execution-trace.json`). Four new cases in `playground/test/engine.test.ts`.
- `changes/R8.md`.

Where the engine still does its own language work (card steps 2 and 3):
- **`intel.ts` keeps its own parse** (through `LanguageHost`). E1 moves it.
- **Check-only constructs and symbols** still come from the syntax tree, because they need ranges and the runtime analysis has none. This means each host builds two service sets (one in `Minab`, one in `LanguageHost`), and each `analyze` parses twice. The card's "Done when" says "only `src/runtime/`"; this is the one gap. See Later.
- The statement's node type and text are found in that tree from the event range (the event has a range only).
