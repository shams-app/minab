## Done
Completion, hover, go to definition and signature help now live in `src/editor/`. The playground engine and the language server call that code. Each of them only converts the result to its own message shape.

- `src/editor/` (new, with a README): `complete`, `hover`, `definition`, `signatureHelp` over an `EditorDocument` (the services of one host and one parsed document) and an offset. No Node, DOM, LSP or Monaco types. Ranges are 0-based line and column.
- Completion: columns after `.` (also after `.customer.`, `^.`, an alias, a record input), tables after `FROM`, `JOIN` and `#`, aliases, loop variables, parameters and `let`s in scope, user `fn`s, host functions and host inputs (with type or signature), built-ins with signatures, and the keywords the grammar allows.
- Hover: column type (and the SQL name when it differs), function signature and doc (built-in, user, host), host input type, `#alias` table, parameter, `let`, any expression's type.
- Definition: `#alias`, a name, a parameter, a `let`, a loop variable, a called `fn`. A bare `#Table` points at itself, as before.
- Signature help: built-ins, user functions and host functions, with the active parameter. It reads the text, so it works on `discounted(` with no closing bracket.
- `playground/src/engine/intel.ts` is now an adapter (the AST view stays there: it is a playground tool). `src/language/lsp/minab-hover-provider.ts` and `minab-definition-provider.ts` call `src/editor/`. So `fn` names get hover and go to definition in the language server now.
- `src/language/schema.ts`: `SchemaProvider` got three small getters (`hostInputs()`, `hostFunctions()`, `tables()`), so the editor can list host names. This file is not on the card's Files list. It is not a protected file, and the change adds methods only.
- Tests: `test/editor/*.test.ts` (55 tests, with `|` cursor markers). `changes/E1.md`.

Small differences from the old behavior (noted on purpose):
- Hover on an unresolved `#alias` gives nothing in the playground now (it gave a line with no table before). The language server never gave one, and its test requires none.
- Completion now offers host inputs and host functions, and backtick insert text for names that are not plain words. The playground shows an input as a `variable` and a host function as a `function` (its protocol has no new kinds).
- Aliases and loop variables are offered where an expression can start, and a parameter is offered only inside its function.
