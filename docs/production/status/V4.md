## Questions for the owner

- **Spec §9.1 and §9.2.** The type of an `if` or a `switch` is now the join of its branches (nullable when a branch
  may be `null`, `DECIMAL` when `INTEGER` and `DECIMAL` mix). The spec says the branch types "must agree", which the
  checker already read as "the same family". Recommendation: add one sentence to §9.1 that says this, through the
  spec-governance cycle. The code follows §7.2 ("a mix is `DECIMAL`") and is not changed by the sentence.
- **Loops over a `JSON` array.** The runtime runs `loop x in .tags { … }` when `.tags` holds an array, but the
  checker says `type.notIterable` as soon as the body reads `x`; and `loop x in 5 { }` passes `check` and fails when
  it runs. Recommendation: decide that a `JSON` array is iterable with `JSON` elements (spec §9.4), then report
  `type.notIterable` on the loop itself for everything else. It is on the post-1.0 list until then.
