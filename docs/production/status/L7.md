# L7 `LOG` and the call statement

Status: done
Date: 2026-10-04
Branch / PR: sema/gracious-goldberg-y1p7zj (pull request: see the branch)

## Done
A program can now print values while it runs. `LOG(value, label?)` records the value and returns it unchanged. A call followed by `;` is a statement. The CLI prints logs on stderr, the playground has a Console tab, and every host gets the lines in the run result and as `log` events. The Depends (L4, L5, R7, R8, X3) were all `done`. D19, D36 and D37 were answered, so nothing was asked.

- Grammar (`src/language/minab.langium`): one rule `AssignmentOrCall` reads the leading expression once; an assignment operator makes an `AssignmentStatement`, `;` makes a new `CallStatement`. A first try with a separate `CallStatement: call=Expression ';'` generated without a warning, but made parsing about 50% slower (two rules starting with an expression), and CI on Node 24 timed out. So the rules share one start. The checker narrows the statement to a call (`call.statementNotACall`). Spec §11 mirrors the grammar.
- Built-ins (`minab-builtins.ts`): `LOG(value, label?)`, return type = type of the value. New parameter kind `any` (a value of any type, also a collection) and a table flag `logs`. In SQL, `LOG(x)` is `x`; the label is not compiled, so no unused parameter is sent to Postgres.
- Checker (`minab-validator.ts`): warning `call.logInSql` for a `LOG` inside a query or inside a filter on a collection. Error `call.statementNotACall`. Both are in the registry; `docs/reference/diagnostics.md` is regenerated.
- Interpreter: evaluates the value, keeps the line in the run budget, emits a `log` event `{ message, value, label, range, time }`, returns the value. A call statement drops its value. `RunBudget.addLog` applies the `logEntries` limit (D36). Over the limit: the line is dropped (no event either), `logsTruncated: true`, not an error.
- Runtime: `RunResult` has `logs` (the lines) and `logsTruncated?`. New `src/runtime/log-format.ts` makes the one-line text (D37).
- CLI: logs on stderr as `file:line:col label: value`; `--no-logs`; `--json` stdout stays clean.
- Playground: Console tab (`ui/output/ConsoleView.tsx`), `RunReport.logs`, hover highlights the call in the editor, click selects it. New gallery example `debug-with-log` (checks its log lines), cheat sheet entry, `LOG` in the tokenizer and in the hover docs (`src/editor/builtin-docs.ts`).
- Docs: spec §5.3.1 row, new §5.3.2 "Debugging with LOG", §8.2, new §9.5 "Call statement", §11; showcase §19.
- Changelog fragments: `changes/L7.md`, `L7-2.md` (CLI), `L7-3.md` (playground).
