## Answers
- D28 (what the data port carries): (a) SQL text plus parameters. A browser never sends SQL; it sends the program id and inputs. A structured request stays as the upgrade path in the ADR. Answered 2026-10-02 and written under D28.
- Review answers (2026-10-02, after the first PR was merged by accident; this is a follow-up PR):
  - `expect: number` accepts `INTEGER` or `DECIMAL`, and `expect` can name any Minab data type (`TEXT`, `BOOLEAN`, `INTEGER`, `DECIMAL`, …). The ADR now says so.
  - Shamsine's M.8 runs stored programs by id and version (id `viewId:nodeId:propertyPath`, version = view revision). Accepted; G2 lists it for the monorepo.
  - The surface schema's `expect` uses the six values. Accepted; G2 lists it.
- D01, D27, D29 to D38 already had answers (A2 sitting, 2026-10-02). The ADR follows them, including D38 (break freely before 1.0).
