## Done
The language server now has the five extras of the card. Each one is computed in `src/editor/` (no LSP types) and `src/lsp/` only converts the results.

- Document symbols (`src/editor/symbols.ts`): each `fn` with its parameters as children, each top-level `let`, and the aliases of the queries outside the functions (joins too).
- Find references and rename (`src/editor/references.ts`) for `let`, parameters, loop variables, `fn` and aliases, in one document. Every use is found with the scope resolver, so a column after `.` is never renamed. `#alias` keeps its `#`. `{ total }` in a JSON object becomes `{ total: newName }`, so the key stays. Rename refuses, with a message from the diagnostic registry, a `fn` name with no lowercase letter (D10), a table or host name (D11), a `let` or parameter that takes a function name, and a duplicate in one scope. It also parses the result and refuses a name that would change what another name means. A name that needs backticks (a space, a keyword, a quote) is written with them; a Persian name stays plain. Prepare rename returns the name range and the current name.
- Semantic tokens (`src/editor/semantic-tokens.ts`): sigils (`.`, `^`, `#`, `$`, `KEY`, `.$index`) as `operator`, keywords, type names, built-ins (`function` + `defaultLibrary`), user functions, host functions and inputs (`host`), fields (`property`), aliases (`namespace`), tables (`class`), parameters and variables, with `declaration` at the declaring name. The legend is `SEMANTIC_TOKEN_TYPES` and `SEMANTIC_TOKEN_MODIFIERS`.
- Quick fixes (`src/editor/quick-fixes.ts`): "Did you mean …?" for `call.unknownFunction` (built-ins, `fn`s, host functions) and `scope.unknownName` (names in scope, host inputs): up to 3, by edit distance, nearest first, ignoring case. "Add CAST(… AS T)" for `type.implicitCoercion`, on either side, using the diagnostic's parameters. No fix when a type has no CAST target (a collection, a record, `null`).
- `src/lsp/server.ts` and `adapters.ts`: the new capabilities. A refused rename is a `RequestFailed` error with the message. The server keeps the diagnostics it last sent for each document, so a quick fix does not depend on the client sending `data` back.
- READMEs of `src/editor`, `src/lsp` and `test/editor` are updated.
