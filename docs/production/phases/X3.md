# X3 — Statements run: blocks, function bodies, assignment, `if!`

| Lane | Kind | Size | Depends | Decisions | Release |
|---|---|---|---|---|---|

## Goal

Everything that changes only **local** values runs: blocks with statements, function bodies with statements, assignment to local names (with `+=`, `-=`, `*=`, `/=`, `?=`, `|=`), and `if!` statements. The function call-depth limit (R4) stops runaway recursion.

## Why now

Today only `let` runs inside a function, so a function with an assignment or an `if!` fails, and a block with any statement fails. This is the base for loops (X4), `LOG(x);` (L7) and writes (X5). It waits for R8 because both change the playground engine's program information.

## Build

1. **Statement runner** in the interpreter: runs `let`, `AssignmentStatement`, `IfStatement` in order inside a block or a function body, then the tail. Each block gets its own frame (inner `let`s shadow outer ones per §7.5 and D24).
2. **Assignment to a local name** (a `let` or parameter):
   - `=` replaces; `+=` adds numbers or joins text (D13); `-=`, `*=`, `/=` numbers (same rules and errors as the operators, C2/C4); `?=` assigns only when the current value is `null`; `|=` merges an object literal into a `JSON` local;
   - assigning to a host input is already a check error (R3).
3. **A target that is a record path** (`.doctor.id = 21;`) or any write: refuse at run time with `eval.writesNotSupported` (X5/X6 implement them) — not a crash, not a silent no-op.
4. **`if!`** with `else if` / `else` branches; the branches are blocks with statements.
5. **Limits**: each user function call counts toward `callDepth` (R4); a deep recursion stops with `limit.callDepth`.
6. **Playground**: the "check-only" list no longer includes these constructs (`playground/src/engine/program.ts` or the runtime's analysis, whichever R8 left in charge); cheat sheet notes; a gallery example with a function that uses a statement.
7. **Spec**: if a section says these "do not run yet", update it. Showcase examples for these constructs must now **run** where they have data (extend L2's spec test to run data-free examples, if L2 is merged).

## Test scenarios

- A function with `let`, `+=` and `if!` returns the right value.
- `let label: TEXT = "order"; label += "-42"; label` is `"order-42"`.
- `discount ?= 0.10;` sets a `null` discount and leaves `0.2` unchanged.
- `let j: JSON = { a: 1 }; j |= { b: 2 }; j` is `{ a: 1, b: 2 }`.
- An inner block's `let x` shadows the outer `x`; after the block the outer value is back.
- `.doctor.id = 21;` → `eval.writesNotSupported`.
- A function that calls itself forever → `limit.callDepth`.

## Done when

No "not executed yet" refusal remains for blocks, function-body statements, local assignment or `if!`; tests and playground green.

## Not here

Loops, `.$index`, tuples (X4). Any write (X5, X6).
