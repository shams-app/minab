# E3 — Language server extras

| Lane | Kind | Size | Depends | Decisions | Release |
|---|---|---|---|---|---|
| E — Editor | Mechanical | M | [E2](E2.md) | — | 0.4.0 |

## Goal

The language server gives document symbols, rename and find-references for names a program declares, semantic highlighting, and quick fixes for the two errors users hit most.

## Why now

The base server is correct (E2); these make it pleasant. They are the last language-server features before 1.0.

## Read

- `src/lsp/` and `src/editor/` READMEs
- `src/language/diagnostics/codes.ts` (codes and params: quick fixes use them)
- `test/lsp-stdio.test.ts` (E2's harness)

## Ask first

None.

## Build

1. **Document symbols**: `fn` (with parameters as children), top-level `let`, query aliases.
2. **Rename and find-references** inside one document for `let`, parameters, `fn` and aliases (not schema names: those belong to the host). Rename refuses (with a message) if the new name breaks D10/D11 rules or is not a valid name (quote it with backticks if L3 is merged and the name needs it).
3. **Semantic tokens**: sigils (`.`, `^`, `#`, `$`, `KEY`), keywords, built-ins, user functions, host functions, host inputs, fields, aliases. Add the legend.
4. **Quick fixes (code actions)**:
   - `call.unknownFunction` and unknown names: "Did you mean …?" (closest names in scope by edit distance, up to 3);
   - `type.implicitCoercion`: "Add CAST(… AS T)" using the diagnostic's params.
5. Tests for each feature through E2's stdio harness or provider-level tests.

## Files

`src/lsp/*`, `src/editor/*` (symbols, references, rename helpers), tests.

## Do not touch

The extension package (E4). `src/cli/main.ts` (a hot file in other lanes).

## Output

A full-featured language server.

## Test scenarios

- Renaming a `let` renames every use and nothing else (not a same-named column after `.`).
- Find-references on a `fn` lists its calls.
- The quick fix for `.status == 5` inserts a `CAST` that makes the diagnostic go away.
- "Did you mean `discounted`?" for `discountd(…)`.
- Semantic tokens mark `.customer` as a field and `COUNT` as a built-in.

## Done when

All five features work and are tested.

## Not here

A code formatter (post-1.0).

## Later

- Folding ranges, inlay hints for inferred types (post-1.0 unless cheap).
- Codes in the CLI's human output behind a `--codes` flag (small; any later phase that already edits `src/cli/main.ts` may take it).

## If it grows

Semantic tokens may move to Later (the TextMate grammar already highlights). Quick fixes and rename must stay.
