## Goal

A web app runs Minab in a Web Worker through the same API as on the server: `createWorkerMinab(...)` gives `prepare` and `run`, the heavy parser stays off the main thread, and the worker can **call back** to ports that live on the main thread (the app's data, its host functions, its clock) and wait for the answer.

## Why now

Shamsine's forms (M.9) run local rules in the browser on every key press. The playground's worker bridge only goes one way (its database lives inside the worker); an app's ports live on the main thread.

## Build

1. **`src/browser/worker.ts`** (entry `./browser/worker`): hosts a runtime inside the worker; answers `create`, `prepare`, `run`, `dispose` messages.
2. **`src/browser/index.ts`** (entry `./browser`): `createWorkerMinab({ worker: () => new Worker(new URL('@shamsine/minab/browser/worker', import.meta.url), { type: 'module' }), schema, functions, inputs, limits })` returns the same shape as `createMinab`, with async `prepare`.
3. **The protocol** (versioned, in `src/browser/protocol.ts`):
   - every request has an id; answers carry it back;
   - **port calls from the worker**: `{ type: 'port-call', callId, port: 'data' | 'functions' | 'clock' | 'events', method, args }` → the main thread runs the app's port and replies `{ type: 'port-result', callId, ok, value | error }`;
   - **cancel**: an `AbortSignal` on the main thread sends `{ type: 'cancel', id }`; the worker aborts that run and its pending port calls;
   - **timeouts**: a port call that gets no answer within the run's wall-time limit fails with `limit.timeout`;
   - **errors** cross as `{ code, message, range?, params }`, never as raw `Error` objects;
   - **values** cross with R6's encoding (decimals as strings, dates as ISO strings);
   - a port may also live **inside** the worker (the playground keeps PGlite there): the host passes a worker-side port module instead of a main-thread one.
4. **Tests that need no browser**: run the worker code in Node with a `MessageChannel` pair standing in for the worker (the bridge logic does not care). Cover: a main-thread data port called from the worker; cancel during a port call; a timeout; an error from a port arrives with its code; two runs at once do not mix answers.
5. README for `src/browser/`.
