## Goal

Minab 0.4.0 is released: every construct the grammar accepts runs (statements, loops, writes, every expression inside queries), the language backlog is closed, `LOG` exists, and the full language server and the polished VS Code extension are published.

## Why now

The execution lane, the language backlog and the editor lane are done.

## Read

- `docs/releasing.md`, `CHANGELOG.md`, `changes/*.md`, `README.md`

## Ask first

- "Is `main` the state you want to release as 0.4.0?"
- "May I push the tag from this session?"

## Build

1. Check Depends and green workflows.
2. Release PR `[V3] Release 0.4.0`: bump, changelog, README (the "not executed yet" limitations are gone: say so), `compat:snapshot 0.4.0`.
3. Tag and release (owner's permission). The extension goes to the Marketplace and Open VSX with E4's listing.
4. **Manual check** (owner): install the extension from the Marketplace; completion after `.`, hover, rename, a quick fix, two folders with different configs. Record the result.
5. Verify from npm as in V2.

## Files

Versions, lockfiles, CHANGELOGs, `changes/*` (deleted), `README.md`, `test/compat/corpus/0.4.0/*`.
