## Build

1. Release PR `[V5] Release 1.0.0`: `bump-version.mjs 1.0.0`; `changelog.mjs --version 1.0.0` with an opening paragraph that states the **1.x compatibility promise** (D38): no breaking change to the language, the runtime API, the wire format or the diagnostic codes within 1.x; deprecations warn first; stored programs keep working (`languageVersion`, golden corpus); `compat:snapshot 1.0.0`; README: "Status: 1.0, stable", the support section, the links to guides.
2. Tag and release (owner's permission); verify from npm (V2's list); the extension on both marketplaces; the website shows 1.0.0 after its next deploy.
3. Tell the owner the launch can go ahead (W5's materials).
