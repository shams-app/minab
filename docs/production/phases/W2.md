# W2 — Build the design: tokens, shell and workbench

| Lane | Kind | Size | Depends | Decisions | Release |
|---|---|---|---|---|---|
| W — Website | Mechanical | M | [W1](W1.md), [L7](L7.md) | — | 1.0.0 |

## Goal

The design system (tokens, primitives, icons), the app shell and the workbench — editor area, toolbar, output panel (Result, SQL, Execution, **Console**, Problems, AST), host panel and overlays — match the approved design. Engine, state, hooks and content are untouched.

## Why now

The design is approved (W1) and the last language change that touches the workbench UI (the Console tab, L7) is in.

## Read

- `playground/design/handoff.md` (W1) and the Claude Design handoff bundle (the owner provides it, Step E)
- `playground/design/contract.md` (what may change), `playground/design/prompts.md` prompt 15 (the wiring prompt)
- `playground/src/ui/**` (shell, workbench, output, host, overlays, primitives), `playground/src/styles/*`, `playground/src/monaco/theme.ts`

## Ask first

If the handoff bundle is not attached: ask the owner for it before starting.

## Build

1. Follow prompt 15's rules: change only `src/ui/**`, `src/styles/**`, icons and assets; **never** `src/engine/**`, `src/state/**`, `src/hooks/**`, `src/content/**`.
2. Tokens first (`tokens.css`, light and dark); then primitives; then shell; then workbench, output panel (including the Console tab's look), host panel, overlays (palette, drawer, toast).
3. Monaco reads the tokens at runtime (`monaco/theme.ts`): check the editor theme follows.
4. **Playground linter** (from B1's Later): use the linter B1 chose (D08: `oxlint`, or ESLint if B1 fell back). Add the playground's lint config and `lint` script, fix findings in the files you touch, and add it to `lint.yml`.
5. Screenshots of the workbench at 1440 px and 375 px, light and dark, attached to the PR (not committed).

## Files

`playground/src/ui/**` (shell, workbench, output, host, overlays, primitives), `playground/src/styles/**`, `playground/src/monaco/theme.ts` (if needed), icons and assets, `playground/.oxlintrc.json` or `playground/eslint.config.js` (new, per B1's choice), `playground/package.json` (lint script), `.github/workflows/lint.yml` (one step).

## Do not touch

Engine, state, hooks, content. Landing, tour, gallery, reference and embed pages (W3).

## Output

The designed workbench.

## Test scenarios

- `npm test` and `npm run build` in `playground/` pass (the suite checks engine and content: it must stay green without changes).
- Keyboard: every control in the workbench is reachable, focus is always visible.
- Reduced motion respected.

## Done when

The workbench matches `handoff.md` in both themes and both widths; tests, build and lint green.

## Not here

Other pages (W3). Deploy (W4).

## Later

None expected.

## If it grows

Overlays (palette, drawer, toast) may move to W3. Tokens, shell and the workbench must stay.
