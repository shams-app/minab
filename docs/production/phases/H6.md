## Goal

`examples/browser/` is a minimal Vite app that (1) validates a form record **in the browser, with zero network calls**, for a rule that needs no data; (2) delegates a correlated rule to the NestJS example (H3) by program id; and (3) shows a Monaco editor with Minab highlighting, live error markers and completion (E5). Playwright tests cover all three in a real browser, in CI.

## Why now

It is the last proof that the browser pieces work together, the way Shamsine will use them, and the code the embedding guide (G1) cites.

## Build

1. `examples/browser/`, its own npm package: Vite + TypeScript, no UI framework. It installs Minab from the packed tarball (like H3).
2. **Page 1, form**: fields of an order (start date, end date, total); a local rule (`.end_date > .start_date`) runs on every change in the worker; a correlated rule (stored program `order-limit` on the H3 server) runs on submit through `routeByTier`. Show the result and any error code.
3. **Page 2, editor**: a Monaco editor registered with E5's `registerMinab`, with the example schema; markers for errors, completion after `.`.
4. **Playwright tests** (`examples/browser/tests/`):
   - local path: change a field, see the verdict, and assert **no request** went to the server;
   - delegated path: submit, see the server's answer, and assert the request body has `program.ref` and no SQL;
   - editor: type a type error, see a marker; type `.` and see a column in the completion list.
5. New workflow `example-browser.yml`: Postgres service, start H3's server, build and preview the Vite app, run Playwright (Chromium).
6. `examples/browser/README.md` (G1 cites it). Exclude `examples/browser/**` from the npm package (`files`).
