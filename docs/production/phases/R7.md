# R7 — The CLI runs on the runtime API

| Lane | Kind | Size | Depends | Decisions | Release |
|---|---|---|---|---|---|
| R — Runtime | Mechanical | M | [R4](R4.md) | — | 0.3.0 |

## Goal

`minab check`, `compile` and `run` are built on `createMinab`/`prepare`/`run`, with no hand wiring of Langium services, and print exactly what they print today. The Postgres executor moves to `src/node/`, where H1 grows it into the Node adapters.

## Why now

The CLI is a real host: moving it is the cheapest proof that the API is complete. H1 needs the Postgres executor in `src/node/`.

## Read

- `src/cli/main.ts`, `src/cli/executors.ts`, `src/cli/config.ts`, `src/cli/diagnostics.ts`
- `src/runtime/` (README, `index.ts`)
- `test/cli.test.ts`, `test/examples.test.ts`

## Ask first

None.

## Build

1. Rewrite the command flows in `src/cli/main.ts` on the runtime API: config → `createMinab` → `prepare` → diagnostics, `compile`, or `run` with the data port (fixture or Postgres) and the event stream (`--trace` prints `statement` events to stderr, as today).
2. Move `PostgresExecutor` from `src/cli/executors.ts` to `src/node/pg.ts` as a `DataPort` (`pgDataPort(client)`), exported from `src/node/index.ts` (replacing R2's stub export for this one name; keep the folder README). The CLI imports it from there. `src/cli/executors.ts` keeps re-exports so old imports work.
3. Output stays the same: exit codes 0/1/2, messages, carets, tables, `--json`. Run-time errors in `--json` gain `code` (and `range` when known). Human output adds nothing.
4. A guard test: `src/cli/` imports only from `src/runtime/`, `src/host/`, `src/node/` and its own files (not from `src/language/` internals). `src/language/main.ts` (the language server) is not part of this.
5. Remove R4's compatibility adapter if R8 has already merged; otherwise leave it and say so in your status file.

## Files

`src/cli/main.ts`, `src/cli/executors.ts`, `src/node/pg.ts` (new), `src/node/index.ts`, `src/node/README.md`, `test/cli.test.ts` (only new assertions for `code` in JSON), `test/cli-imports.test.ts` (new).

## Do not touch

The playground (R8). Node adapters beyond the moved executor (H1).

## Output

A CLI that proves the API; `src/node/pg.ts` for H1.

## Test scenarios

- Every existing CLI and examples test passes **unchanged** (if one must change, explain why in the status file).
- `minab run --json` on a failing cast prints `"code": "eval.castFailed"`.
- The import guard fails if `src/cli/main.ts` imports `../language/minab-interpreter.js` (try, undo).

## Done when

The CLI runs on the API with unchanged behavior; the executor lives in `src/node/`.

## Not here

New CLI features (logs come with L7, writes with X5).

## Later

None expected.

## If it grows

It should not.
