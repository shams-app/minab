# H7 — The playground uses the published browser entry

| Lane | Kind | Size | Depends | Decisions | Release |
|---|---|---|---|---|---|
| H — Hosts | Mechanical | S | [H5](H5.md), [E1](E1.md), [L7](L7.md) | — | 0.3.0 |

## Goal

The playground's worker and client are built on `./browser` and `./browser/worker` (with PGlite as a worker-side port), so the playground runs the same browser runtime Shamsine uses. Duplicate bridge code is gone.

## Why now

The playground is the most-used host: if it runs on the published entry, every visitor tests it. E1 (`intel.ts`) and L7 (the Console's log transport) change the playground engine first, so this phase does not collide with them.

## Read

- `src/browser/` README (H4, H5)
- `playground/src/engine/worker.ts`, `engine.ts`, `database.ts`, `protocol.ts`, `playground/src/client/engine-client.ts`
- `playground/test/*`

## Ask first

None.

## Build

1. The playground's worker uses `src/browser/worker.ts` with a worker-side PGlite data port (from `./browser/pglite`, or `database.ts` adapted to the `DataPort` shape).
2. `engine-client.ts` becomes a thin layer over `createWorkerMinab`, keeping the methods the UI hooks call (restartable, as today).
3. Remove the playground's own copy of anything `src/browser/` now provides.
4. Compare the playground's production bundle size before and after; write both in your status file. It must not grow by more than 5%.

## Files

`playground/src/engine/worker.ts`, `engine.ts`, `database.ts`, `playground/src/client/engine-client.ts`, playground tests only where internals changed.

## Do not touch

`playground/src/ui/**`, `src/browser/` (report problems).

## Output

One browser runtime for the playground and for apps.

## Test scenarios

- The playground suite passes unchanged.
- A manual check (`npm run dev`): run a gallery example, cancel a long run, restart the engine. Write the result in your status file.

## Done when

The playground runs on the published browser entry, tests and build are green, the bundle did not grow by more than 5%.

## Not here

Design changes (W2, W3).

## Later

None expected.

## If it grows

It should not.
