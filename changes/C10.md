Literal-only parts of an expression, such as `.total > 50 + 50` or `.price * (1 + 0.2)`, now run in Postgres. Before, Postgres refused them, or compared two literals as text. `is array`, `is object`, `is string`, `is number` and `is boolean` on a value that is not `JSON` are now the check error `type.kindTestNeedsJson`. `is null` still works on every type. A user function that reads `.`, `^` or `#alias` can no longer be used inside a query: `check` reports `query.functionNotInlinable`.
