A second `let` with the same name in the same scope, and `!` on a collection step of an assignment path, are now errors (`scope.duplicateLet`, `type.vivifyOnCollection`). Comparing a relation with a key (`.customer == x`) is the error `type.relationComparedToKey`, which names the long form `.customer.id`.
