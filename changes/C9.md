A `null` value now gives one answer in the interpreter and in the compiled SQL. Arithmetic with a `null` operand gives `null` (also `null / 0`), and `<`, `<=`, `>`, `>=` and `LIKE` with a `null` operand give `false` instead of an error. `IN` is never `null` in SQL (`null IN [1, null]` is `true`), `IN` with a subquery now runs in the interpreter, and a JSON `null` counts as `null` for `is null` and `== null`.
