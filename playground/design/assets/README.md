# design/assets

Sources for the raster icons in `public/` (W2). Open a file in a browser; the fonts load from `public/fonts/`.

| File | Renders to |
|---|---|
| `apple-touch-icon.html` | `public/apple-touch-icon.png` (180 × 180, element `#icon`) |
| `og-image.html` | `public/og-image.png` (1200 × 630, element `#og`) |

Rules:
- The artwork comes from the approved design (`../handoff.md`, round 1 and board 18).
- To render: screenshot the element in the comment with Chromium at scale 1.
- `public/favicon.svg` is hand-written SVG. Change it together with these files.
